# Local game audio

Audio is generated locally from the user's Mario 64 and GoldenEye ROMs. This
directory contains the runtime boundary and documentation only; it does not
contain ROM audio, extracted samples, or generated binaries.

The future audio manager will select music by game state:

- Mario hub and painting-entry jingle;
- GoldenEye briefing and Dam mission music;
- combat/alert music;
- mission success and failure music.
